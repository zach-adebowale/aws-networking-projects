# AWS Networking Projects

A collection of AWS infrastructure projects covering core networking, 
compute, and load balancing built and documented from scratch.

## Projects

### 1. VPC Networking
Custom VPC built from scratch covering subnet segmentation, internet 
and NAT routing, EC2 deployment, and secure internal access via a 
bastion host.

[View project →](vpc-networking/README.md)

### 2. ALB Compute
Production-style setup deploying EC2 instances behind an Application 
Load Balancer across two availability zones with HTTPS termination 
via ACM, and DNS managed through Cloudflare.

[View project →](alb-compute/README.md)

## Skills demonstrated

- VPC architecture and subnet design
- Internet and NAT gateway configuration
- EC2 deployment and security group management
- Application load balancing and HTTPS termination
- Auto Scaling Group configuration
- DNS management and SSL certificate provisioning
- CloudWatch monitoring
